# Dating Safety Guide

Independent 18+ editorial guide: what to check before paying for a dating app.

Live site: https://www.datesafelyguide.com

Paper-and-ink layout (not a SaaS landing page). Partner links for dating sites in the visitor’s region are disclosed on the page.

Covers:
- Recurring billing traps and cancellation
- Privacy settings that actually matter
- Dating scam red flags
- App comparison (Tinder, Bumble, Hinge, Badoo)
- AI companions vs dating apps

Static HTML. Outbound `/go` is the tracked partner redirect.
